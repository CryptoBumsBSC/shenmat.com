# Shen Academy Website — V5 Final Build

.com — Shen Academy Burnie

Static 2026 website for Shen Academy, Burnie, Tasmania.

No CMS, database or plugin stack is required. The HTML, CSS and image files in this folder are the complete site. GitHub is not required.

## Included

- 35 HTML pages: home, classes, timetable, school programs, about, FAQ, contact, 19 local area pages and 404
- Responsive mobile navigation and mobile call/text/timetable dock
- Supplied Shen Academy logo, family campaign artwork and 2026 MAA Accredited School badge
- Open Graph share image and Apple touch icon
- Schema.org JSON-LD for the academy, services, FAQs and breadcrumbs
- robots.txt, llms.txt and sitemap.xml
- Security and clean-URL rules in vercel.json

## Test or deploy

You can open the supplied single-file homepage preview to review the design. For a live test, serve this folder with any static web server. The production folder can be uploaded to any static host; `vercel.json` is included if Vercel is used.

See `EDITING.md` for class times, fees, phone, address and content updates.
